Install

Install AIPL

One command, no git, no Rust, and nothing runs as root. It downloads the release for your machine, checks it against its published SHA-256, and unpacks it into ~/.aipl.

supported x86-64 and AArch64. Needs curl and tar, and glibc 2.35 or newer.

curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/mwarpinski/AIPL/main/install.sh | sh

You get aipl, the compiler written in AIPL, and aipl-net, a small helper for host names and HTTPS, plus the standard library and the documentation, and ~/.aipl/bin on your PATH.

preview Apple silicon. Needs curl and tar.

curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/mwarpinski/AIPL/main/install.sh | sh
macOS gets the Rust build of aipl and aipl-run for now, and the binary is not notarised, so macOS may ask you to allow it. compile --exe there makes a 15 to 20 MB file that bundles the launcher. Native executables on macOS need a Mach-O backend, which is next on the roadmap.

preview Windows 10 or 11, x86-64. In PowerShell:

irm https://raw.githubusercontent.com/mwarpinski/AIPL/main/install.ps1 | iex

It needs no git, no Rust, no Visual C++ runtime and no administrator rights. It unpacks into %USERPROFILE%\.aipl and adds its bin to your user PATH; open a new terminal to see it.

A program on Windows sees the root of the drive it runs from as / and reaches no other drive, and the installer is not code-signed, so SmartScreen may warn. compile --exe makes a single file that bundles the launcher.

Then

aipl --version aipl doc str | head

Write a file, aipl verify it, aipl run it. The ten-minute tour goes through the language, and Using AIPL covers build, run and test.

Read the installer first

It is about 300 lines of POSIX sh.

curl --proto '=https' --tlsv1.2 -sSfO https://raw.githubusercontent.com/mwarpinski/AIPL/main/install.sh less install.sh && sh install.sh

sh install.sh --help lists the options: --version installs a release other than the latest, --no-modify-path leaves your shell files alone. Run it again to update; sh install.sh --uninstall removes everything it put there.

Verify a download

Each release on the releases page lists SHA-256 sums for every file, and the list is signed with Sigstore (keyless, from the release workflow in this repository). RELEASING.md has the commands to check a signature by hand.

Build it from source

On Linux, x86-64 or AArch64, you need only git and a POSIX shell. The repository holds a seed, a compiler built earlier, and one script builds the compiler from the sources with it: no Rust, no network.

git clone https://github.com/mwarpinski/AIPL.git && cd AIPL sh bootstrap/build.sh

The script builds the compiler with the seed, builds it again with the result, and checks that a third build is identical. The result is target/bootstrap/aipl. On macOS and Windows, and to run the Rust referee, you need a stable Rust toolchain; sh install.sh --from-source does it for you.

Status

Early, and honest about it

The language, the standard library and both compilers work and are heavily tested. Everything here that is unfinished, we would rather you read from us first.

Platforms

PlatformStatusWhat it ships
Linux x86-64supportedThe self-hosted aipl, built from the checked-in seed with no Rust compiler, and aipl-net, the one Rust helper (host names and HTTPS). Native executables.
Linux AArch64supportedThe same, built on an AArch64 machine. CI tests it on arm64 runners; the installer has not been run on a physical one.
macOS (Apple silicon)previewThe Rust aipl and aipl-run. compile --exe bundles the launcher (15 to 20 MB). Not notarised. Checked by hand.
Windows 10/11 (x86-64)previewThe same, with a PowerShell installer. Not code-signed. A program sees only the drive it runs from. Built and tested in CI.

What has not been measured

The question the project exists to answer is whether agents write correct programs more often in AIPL than in other languages. That has not been measured yet. The harness exists; the measurement, with its tasks, prompts, transcripts and numbers, including where AIPL loses, comes after launch. Until then, every claim about helping agents is a design intent, not a result.

What is not there

  • Stability. Modules can declare the language version they were written for, but nothing yet promises that a program written today builds next year.
  • Packages and a registry. Imports resolve by file name through a search path.
  • A language server. Editor grammars (TextMate and tree-sitter) and a VS Code extension exist; they are not published to a marketplace.
  • Native executables off Linux. Mach-O and PE backends are the next large piece of work.
  • TLS written in AIPL. HTTPS goes through the small Rust helper aipl-net.
  • Speed like C. It is not as fast; the benchmark table says how far behind, and what the overflow checks cost.

The full list, with each limit and the way around it, is in LIMITS.md; what comes next, in order, is in the roadmap.

How it was built

The language is designed by Matt Warpinski and implemented with AI coding agents; the commit messages say so. Because of that the project leans on checking: two independent compilers that must agree on every program, an interpreter and two backends that must agree, fuzzers on every push, a compiler that rebuilds itself to a fixed point from a hash-checked seed, and documents checked against the code.

Found a security problem? SECURITY.md says how to report it.
